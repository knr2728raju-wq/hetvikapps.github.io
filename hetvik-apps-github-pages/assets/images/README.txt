Image placeholders
==================
This folder holds site imagery. The site works as-is using built-in
SVG/CSS placeholders, but for production you should add:

- App icon:      replace the <div class="app-icon"> in apps.html, or
                 drop a 512x512 PNG here and reference it.
- Screenshots:   replace the <div class="app-shot"> blocks in apps.html
                 with real phone screenshots (recommended 1080x1920).
- og-image.svg:  social share image (1200x630) — already provided.
- favicon.svg:   browser tab icon — already provided.

Everything else (backgrounds, orbs, phone mockup) is pure CSS/SVG.
